## Featured projects

### [Apate](https://github.com/rachit23tech/Apate) · AI risk manager and fraud-spike detector
[Live demo](https://apate.onrender.com) · React, FastAPI, XGBoost, LightGBM, WebLLM

- XGBoost + LightGBM ensemble trained on 199K+ transactions with 37 engineered features, at a 0.19% fraud rate.
- A cost-tuned decision threshold reaches **75% recall and 68% precision** on held-out data and cuts the cost of fraud errors by **85%** against a baseline.
- An in-browser LLM assistant explains each fraud flag with zero external API calls.

### [Bifrost](https://github.com/rachit23tech/Bifrost) · URL shortener with abuse detection and live analytics
[Live demo](https://bifrost-bebl.onrender.com) · React, TypeScript, Express, WebSocket, SQLite

- Scores every submitted link from **0 to 100** on 7 weighted threat signals, then allows, flags or blocks it before redirect.
- Click events stream over WebSockets to a live dashboard with 24h trend, geo, device and referrer breakdowns.
- JWT authentication, Base62 short links, deployed as a single Docker container on Render.

### [Styx](https://github.com/rachit23tech/Styx) · Smart expense tracker
[Live demo](https://styx02.netlify.app/) · React, TypeScript, Node.js, Express, MongoDB, Gemini API

- A 3-tier categorisation engine resolves **90%+** of recurring transactions with deterministic rules in **under 5 ms**.
- A feedback loop turns a user's repeated corrections into permanent rules, cutting LLM API costs by **95%**.
- Spending metrics are computed exactly with MongoDB aggregation pipelines; the LLM only writes the insights.
